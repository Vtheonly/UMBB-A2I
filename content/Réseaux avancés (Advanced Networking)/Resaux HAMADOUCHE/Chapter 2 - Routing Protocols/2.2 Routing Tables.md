
# 2.2. Routing Tables

### **Definition**
The **Routing Table** is a data file stored in the router's RAM. It acts as the map for the router, listing available destinations and instructions on how to reach them.

### **Components of a Routing Entry**
A standard entry in the table contains:
1.  **Destination Network:** The network address (Net_ID) you want to reach.
2.  **Subnet Mask:** Defines the size of the destination network.
3.  **Next Hop / Interface:**
    *   *Directly Connected:* The exit interface (e.g., `GigabitEthernet0/0`).
    *   *Remote Network:* The IP address of the *next* router in the path.

### **Route Types (Sources)**
The command `show ip route` (on Cisco devices) displays codes indicating how a route was learned:

| Code | Type | Description | Administrative Distance (Default) |
| :--- | :--- | :--- | :--- |
| **C** | **Connected** | Networks physically attached to the router's active interfaces. Added automatically. | 0 |
| **L** | **Local** | The specific IP address assigned to the router's interface (/32). | 0 |
| **S** | **Static** | Manually configured by an administrator. | 1 |
| **R** | **RIP** | Learned dynamically via the RIP protocol. | 120 |
| **O** | **OSPF** | Learned dynamically via the OSPF protocol. | 110 |
| **D** | **EIGRP** | Learned dynamically via the EIGRP protocol. | 90 |
| **S\***| **Default** | The "Route of Last Resort" (0.0.0.0/0). Used when no other specific match exists. | 1 |

> [!NOTE] **Directly Connected Routes**
> For a "Connected" route to appear in the table, the interface must be configured with an IP **AND** the interface status must be "Up/Up" (Layer 1 and Layer 2 active).
