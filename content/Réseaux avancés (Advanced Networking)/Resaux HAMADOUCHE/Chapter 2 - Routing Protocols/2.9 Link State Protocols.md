
# 2.9. Link State Protocols (OSPF)

### **Concept: "Map Routing"**
Unlike Distance Vector, Link State routers do not rely on rumors. Every router builds a **complete, identical map** of the entire network topology.

### **The Dijkstra Algorithm (SPF)**
*   **S**hortest **P**ath **F**irst.
*   Each router places itself at the root of a tree and calculates the shortest path to every other node in the map.

### **Operation Stages**
1.  **Neighbor Discovery:** Routers send **Hello Packets** to find directly connected neighbors and establish adjacency.
2.  **LSA Flooding:** Routers flood **Link State Advertisements (LSAs)**. An LSA says: "I am Router X, my neighbors are Y and Z, and the link cost is 10."
3.  **LSDB Creation:** Each router collects all LSAs to build the **Link State Database (LSDB)**. *Note: All routers in the same area have the exact same LSDB.*
4.  **SPF Calculation:** The router runs Dijkstra's algorithm on the LSDB to calculate the best routes.
5.  **Routing Table:** The best paths are installed in the Routing Table.

### **OSPF (Open Shortest Path First)**

#### **1. Metric: Cost**
OSPF uses **Cost** as its metric, which is derived from **Bandwidth**.
$$Cost = \frac{\text{Reference Bandwidth}}{\text{Interface Bandwidth}}$$
*   **Default Reference BW:** $10^8$ (100 Mbps).
*   *Example:*
    *   Fast Ethernet (100 Mbps) = $10^8 / 10^8 = 1$
    *   Ethernet (10 Mbps) = $10^8 / 10^7 = 10$
*   *Limitation:* With the default reference, 100Mbps, 1Gbps, and 10Gbps all equal Cost 1. Administrators must change the reference bandwidth command (`auto-cost reference-bandwidth`) to differentiate high-speed links.

#### **2. Hierarchy: Areas**
To prevent the LSDB from becoming too big and the SPF calculation from taking too much CPU, OSPF divides the network into **Areas**.

*   **Area 0 (Backbone Area):** The core of the network. **Mandatory**.
*   **Normal Areas:** Must connect directly to Area 0.
*   **Benefit:** Detailed topology is hidden inside an area. Area 1 only knows "summary" information about Area 2. This stops a flapping link in Area 1 from forcing routers in Area 2 to recalculate SPF.

#### **3. Router Roles**
*   **IR (Internal Router):** All interfaces are in the same area.
*   **BR (Backbone Router):** Has at least one interface in Area 0.
*   **ABR (Area Border Router):** sits between Area 0 and another area. It holds the LSDB for *both* areas.
*   **ASBR (Autonomous System Boundary Router):** Connects the OSPF network to an external network (like the Internet or a RIP network).

#### **4. OSPF Packet Types**
1.  **Hello:** Discovers neighbors and acts as a "Keepalive" (heartbeat).
2.  **DBD (Database Description):** Summary of the LSDB (used when syncing).
3.  **LSR (Link State Request):** "I don't have information about this link, please send it."
4.  **LSU (Link State Update):** Contains the actual LSAs (the detailed info).
5.  **LSAck:** Acknowledges receipt of an LSU (Reliability).

> [!NOTE] **Comparison: RIP vs OSPF**
> *   **Convergence:** OSPF is fast (triggered updates). RIP is slow (periodic).
> *   **Knowledge:** OSPF knows the whole map. RIP knows only the next hop.
> *   **Resource Usage:** OSPF uses more CPU/RAM initially (to build the map) but less bandwidth later (only changes are sent). RIP uses little CPU but constant bandwidth.
