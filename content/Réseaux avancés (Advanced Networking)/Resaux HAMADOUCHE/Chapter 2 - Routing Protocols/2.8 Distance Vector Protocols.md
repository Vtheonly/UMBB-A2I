
# 2.8. Distance Vector Protocols (RIP)

### **Concept: "Rumor Routing"**
Distance Vector protocols function based on "hearsay." A router knows **nothing** about the complete network topology. It only knows:
1.  **Distance:** How far away a network is (metric).
2.  **Vector:** Which direction (interface/neighbor) to send traffic.

### **The Bellman-Ford Algorithm**
This is the mathematical engine behind Distance Vector routing.
*   **Process:** Every router sends its *entire* routing table to its direct neighbors periodically.
*   **Calculation:** If Neighbor A says "I can reach Network X in 3 hops," and I am connected to Neighbor A (1 hop), then I can reach Network X in 4 hops (3+1).

### **RIP (Routing Information Protocol)**
RIP is the classic example of a Distance Vector protocol.

#### **1. Key Characteristics**
*   **Metric:** **Hop Count** (number of routers crossed).
*   **Limits:**
    *   Valid hops: 0 to 15.
    *   **16 Hops = Infinity** (Unreachable). This limits RIP to small networks (diameter < 15 routers).
*   **Updates:** Sends the **full routing table** every **30 seconds** via Broadcast (v1) or Multicast (v2).
*   **Transport:** UDP Port **520**.

#### **2. RIP Versions**

| Feature | RIPv1 | RIPv2 |
| :--- | :--- | :--- |
| **Addressing** | Classful (No subnet masks sent) | Classless (Sends Subnet Masks - Supports VLSM) |
| **Updates** | Broadcast (255.255.255.255) | Multicast (224.0.0.9) |
| **Security** | None | Supports MD5 Authentication |

#### **3. The "Count to Infinity" Problem & Solutions**
Because routers only believe neighbors, loops can cause metrics to increment infinitely (until 16) during a failure. RIP uses mechanisms to prevent this:

*   **Split Horizon:** A router typically learns a route from a neighbor. **Rule:** Never send a route advertisement *back* to the neighbor you learned it from.
    *   *Logic:* If I learned about Network X from Router B, Router B is closer to X than I am. Telling Router B "I can reach X" is useless and creates loops.
*   **Route Poisoning:** When a link goes down, the router doesn't just delete the route. It advertises it with a metric of **16 (Infinity)** to explicitly tell neighbors "This route is dead."
*   **Hold-down Timers:** If a route fails, the router waits a specific time (180s) before believing a new update about that route (unless the update comes from the original source). This prevents believing incorrect info from delayed packets.

> [!TIP] **Exam Warning**
> Remember that **RIPv1** does **not** send subnet masks. This means you cannot use VLSM or disjoint subnets with RIPv1. Always assume RIPv2 in modern contexts unless specified otherwise.
