
# 2.5. Types of Routing

There are two fundamental ways to populate a routing table:

### **1. Static Routing**
The administrator manually types in the routes.
*   **Command:** `ip route [Network] [Mask] [Next-Hop-IP]`
*   **Pros:**
    *   **Secure:** No advertisements sent over the network (topology is hidden).
    *   **Resource Friendly:** No CPU overhead for calculations; no bandwidth used for updates.
    *   **Predictable:** Traffic always follows the path you set.
*   **Cons:**
    *   **Non-Adaptive:** If a link breaks, the traffic drops. The router cannot automatically switch to a backup path.
    *   **High Maintenance:** Adding a new subnet requires updating *every* router manually. Infeasible for large networks.

### **2. Dynamic Routing**
Routers use software protocols (like OSPF, RIP, BGP) to talk to each other.
*   **Mechanism:**
    1.  Routers "discover" neighbors.
    2.  They exchange information about networks they know.
    3.  They calculate the best path automatically.
*   **Pros:**
    *   **Scalable:** Easy to add new networks; routers update themselves.
    *   **Resilient:** If a link fails, the protocol detects it and recalculates a new path (Convergence).
*   **Cons:**
    *   **Overhead:** Consumes CPU, RAM, and Bandwidth.
    *   **Complexity:** Requires careful configuration to avoid loops and instability.
