
# 2.6. Routing Metrics and Distance

When a router has multiple ways to reach the **exact same network** (same prefix length), it needs tie-breakers to decide which path to install in the routing table.

### **1. Administrative Distance (AD) - The "Trust" Rating**
AD is used to choose between **different sources/protocols** (e.g., Static vs. OSPF).
*   **Concept:** Who do I trust more?
*   **Scale:** 0 to 255. **Lower is better.**

| Source | Default AD | Reasoning |
| :--- | :--- | :--- |
| **Connected** | 0 | Most trusted (physical connection). |
| **Static** | 1 | Administrator overrides dynamic protocols. |
| **EIGRP** | 90 | Cisco proprietary, very reliable. |
| **OSPF** | 110 | Standard link-state protocol. |
| **RIP** | 120 | Older distance-vector, less trusted. |
| **Unknown** | 255 | Not trusted, route is ignored. |

*   **Example:** If a router learns the path to `10.1.1.0/24` via **OSPF** (AD 110) and via **Static Route** (AD 1), it installs the **Static Route** because 1 < 110.

### **2. Metric - The "Cost" Rating**
Metric is used to choose paths **within the same protocol**.
*   **Concept:** Which path is "shorter" or "faster"?
*   **Scale:** Varies by protocol. **Lower is usually better.**

| Protocol | Metric Used | Description |
| :--- | :--- | :--- |
| **RIP** | **Hop Count** | Number of routers to cross. Max 15. |
| **OSPF** | **Cost** | Based on Bandwidth ($10^8 / Bandwidth$). Faster link = Lower cost. |
| **EIGRP** | **Composite** | Math formula using Bandwidth, Delay, Load, Reliability. |

*   **Example (RIP):** Path A has 2 hops. Path B has 4 hops. RIP chooses Path A.
*   **Example (OSPF):** Path A is a 56kbps line (high cost). Path B is a 1Gbps line (low cost). OSPF chooses Path B, even if it has more hops.

### **Selection Hierarchy**
When deciding routing:
1.  **LPM:** Does the packet match the route? (Most bits match wins).
2.  **AD:** Are there multiple protocols offering this specific route? (Lowest AD wins).
3.  **Metric:** Does the chosen protocol have multiple paths? (Lowest Metric wins).
