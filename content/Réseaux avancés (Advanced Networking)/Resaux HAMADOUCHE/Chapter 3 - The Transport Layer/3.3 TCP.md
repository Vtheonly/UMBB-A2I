
## 3.3. Transport Protocols: TCP vs. UDP
Different applications have different requirements regarding reliability and speed. The TCP/IP stack provides two main protocols at Layer 4.

### 3.3.1. TCP (Transmission Control Protocol)
**Philosophy:** "Reliability above all else."

*   **Connection-Oriented:** A logical connection must be established (3-way handshake) before data transfer begins.
*   **Reliable Delivery:** Guarantees data arrives. If a packet is lost, it is retransmitted.
*   **Ordered Delivery:** Data is reassembled in the exact order it was sent, even if packets arrived out of order.
*   **Flow Control:** Manages data flow so the receiver isn't overwhelmed.
*   **Heavyweight:** Higher overhead (larger header, more processing) due to acknowledgments and tracking.

**Use Cases:** Web browsing (HTTP/HTTPS), Email (SMTP/POP/IMAP), File Transfer (FTP). *Reasoning: You cannot afford to lose a single byte of a file or have email text scrambled.*

### 3.3.2. UDP (User Datagram Protocol)
**Philosophy:** "Speed and efficiency." (Also known as "Fire and Forget").

*   **Connectionless:** No setup phase. Data is sent immediately.
*   **Unreliable (Best Effort):** No acknowledgments. If a packet is lost, it is gone.
*   **Unordered:** Data is processed as it arrives.
*   **No Flow Control:** The sender blasts data as fast as the application allows.
*   **Lightweight:** Very small header (low overhead), very fast processing.

**Use Cases:** Streaming (Video/Audio), VoIP (Voice over IP), DNS, Online Gaming. *Reasoning: In a live video call, if a packet is lost, it's better to skip that frame and keep playing the live stream than to pause everything to retrieve the lost frame.*

### 3.3.3. Comparison Summary

| Feature | TCP | UDP |
| :--- | :--- | :--- |
| **Reliability** | High (Ack + Retransmit) | Low (No Ack) |
| **Connection** | Connection-oriented | Connectionless |
| **Ordering** | Guaranteed | Not Guaranteed |
| **Speed** | Slower (Overhead) | Faster (Low Overhead) |
| **Header Size** | 20 Bytes (min) | 8 Bytes |
| **Services** | Flow/Congestion Control | None |
