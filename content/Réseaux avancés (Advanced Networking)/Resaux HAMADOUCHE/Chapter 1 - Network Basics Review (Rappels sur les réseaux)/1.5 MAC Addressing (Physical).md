
# 1.5. MAC Addressing and Ethernet

## 1. MAC Address (Physical Address)
The **Media Access Control (MAC)** address is a unique identifier burned into the Network Interface Card (NIC). It is used for communication within the **same** local network segment (Layer 2).

### Format
*   **Length:** 48 bits (6 bytes).
*   **Notation:** 12 Hexadecimal digits (e.g., `00:0B:DB:16:E7:8A`).

### Structure
1.  **OUI (Organizationally Unique Identifier):** The first 3 bytes (24 bits). Identifies the **Manufacturer** (e.g., Cisco, Intel). Assigned by IEEE.
2.  **NIC Controller:** The last 3 bytes (24 bits). Unique serial number assigned by the vendor.

### Significant Bits in the OUI
The first byte contains two special flags:
*   **I/G Bit (Individual/Group):**
    *   `0`: Unicast address (Specific device).
    *   `1`: Multicast/Broadcast address (Group of devices).
*   **U/L Bit (Universal/Local):**
    *   `0`: Universally unique (Burned-in).
    *   `1`: Locally administered (Changed by software).

### Address Types
1.  **Unicast:** `00-50-56-C0-00-08` (One receiver).
2.  **Broadcast:** `FF-FF-FF-FF-FF-FF` (All devices on the LAN).
3.  **Multicast:** `01-00-5E-xx-xx-xx` (Specific group, used for video/routing updates).

## 2. Ethernet Frame
Ethernet is the dominant Layer 2 technology. It wraps the Layer 3 Packet into a Frame. (it's going from top to down)

### Frame Structure
| Field | Size | Function |
| :--- | :--- | :--- |
| **Preamble** | 7 Bytes | Synchronization (Alerts card data is coming). |
| **SFD** | 1 Byte | Start Frame Delimiter. |
| **Dest MAC** | 6 Bytes | Who is this for? |
| **Source MAC** | 6 Bytes | Who sent this? |
| **Type/Len** | 2 Bytes | Indicates the Layer 3 protocol (e.g., 0x0800 for IPv4, 0x0806 for ARP). |
| **Data** | 46-1500 B | The Payload (IP Packet). Padding is added if data < 46 bytes. |
| **FCS (CRC)** | 4 Bytes | Error checking. If CRC calculation fails, frame is dropped. |

> [!WARNING] **Common Trap**
> A MAC address is **Flat**, meaning it has no hierarchy (like a Social Security Number). An IP address is **Hierarchical** (like a postal address: Country -> City -> Street). MACs work purely locally; they do not cross routers.
