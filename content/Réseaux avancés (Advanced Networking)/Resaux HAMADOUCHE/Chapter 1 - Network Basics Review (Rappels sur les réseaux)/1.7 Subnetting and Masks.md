

## 1. The Need for Subnetting
Originally, IP classes (A, B, C) allocated addresses in huge blocks.
*   **Problem:** If you need 6000 IPs, a Class B (65,534 IPs) wastes ~59,000 addresses.
*   **Solution:** **Subnetting**. Breaking a single large network ID into smaller, manageable pieces called subnets.

## 2. The Subnet Mask
The mask is a 32-bit sequence used by the computer to distinguish which part of an IP address is the **Network** and which part is the **Host**.

*   **Logic:**
    *   **1s (Ones):** Represent the Network portion.
    *   **0s (Zeros):** Represent the Host portion.
*   **AND Operation:** The router performs a logical `AND` between the IP Address and the Subnet Mask to calculate the **Network Address**.

### CIDR Notation (Classless Inter-Domain Routing)
Instead of writing `255.255.255.0`, we use **Prefix Notation** (slash notation). It counts the number of "1" bits in the mask.
*   `255.0.0.0` = `/8`
*   `255.255.0.0` = `/16`
*   `255.255.255.0` = `/24`

---

## 3. How to Subnet (The Calculation)
To create subnets, we **borrow bits** from the Host portion and give them to the Network portion.

### The Formulas
1.  **Number of Subnets:** $2^b$ (where $b$ is the number of borrowed bits).
2.  **Number of Hosts per Subnet:** $2^h - 2$ (where $h$ is the remaining host bits).
    *   *Why -2?* One for the Network ID (all 0s) and one for the Broadcast Address (all 1s).

### Example: Creating 5 Subnets from 172.130.0.0/16
*   **Base Network:** `172.130.0.0` (Class B, Default `/16`).
*   **Requirement:** 5 subnets.
*   **Calculation:**
    *   $2^b \ge 5$.
    *   If $b=2$, $2^2=4$ (Not enough).
    *   If $b=3$, $2^3=8$ (Enough). We borrow **3 bits**.
*   **New Mask:** Original `/16` + 3 borrowed bits = `/19`.
    *   Binary: `11111111.11111111.11100000.00000000`
    *   Decimal: `255.255.224.0`
*   **Increment (Magic Number):** The value of the lowest borrowed bit. Here, it is the 3rd bit in the 3rd octet ($128, 64, \mathbf{32}$). The increment is **32**.

| Subnet # | Network Address | First Usable IP | Last Usable IP | Broadcast Address |
| :--- | :--- | :--- | :--- | :--- |
| **0** | 172.130.0.0 | 172.130.0.1 | 172.130.31.254 | 172.130.31.255 |
| **1** | 172.130.32.0 | 172.130.32.1 | 172.130.63.254 | 172.130.63.255 |
| **2** | 172.130.64.0 | 172.130.64.1 | 172.130.95.254 | 172.130.95.255 |
| ... | ... | ... | ... | ... |

> [!TIP] **FLSM (Fixed Length Subnet Mask)**
> Traditional subnetting uses the **same mask** for all subnets. If one building needs 500 IPs and another needs 20, using the same large mask for both leads to waste. This is solved by VLSM.
