
## 1. Context
With the explosion of the internet, the 4.3 billion IPv4 addresses were not enough. To conserve addresses, the concept of **Private Addressing** (RFC 1918) was introduced.

---

## 2. Comparison

| Feature | **Public IP** | **Private IP** |
| :--- | :--- | :--- |
| **Scope** | Global (The Internet). | Local (LAN/Intranet). |
| **Uniqueness** | Must be unique worldwide. | Must be unique only within the local network. |
| **Routing** | **Routable** on the Internet backbone. | **Not Routable** on the Internet. Routers drop packets with these destination IPs. |
| **Cost** | Paid (Leased from ISP). | Free. |
| **Assignment** | Controlled by IANA/ICANN/ISP. | Assigned by Administrator (or DHCP). |

---

## 3. The Private Ranges (RFC 1918)
You should memorize these ranges. If you see an IP in these ranges, it is definitely inside a LAN.

| Class | Range Start | Range End | CIDR | Typical Use |
| :--- | :--- | :--- | :--- | :--- |
| **A** | `10.0.0.0` | `10.255.255.255` | `10.0.0.0/8` | Large Enterprises |
| **B** | `172.16.0.0` | `172.31.255.255` | `172.16.0.0/12` | Medium orgs / Docker containers |
| **C** | `192.168.0.0` | `192.168.255.255` | `192.168.0.0/16` | Home routers / Small Office |

> [!NOTE] **APIPA (Automatic Private IP Addressing)**
> If you see an address starting with `169.254.x.x`, it is not a standard private address. It means the device failed to contact a DHCP server and assigned itself a link-local address. It cannot browse the internet.
