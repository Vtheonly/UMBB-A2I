## 1. Definition
An IP Address is a **Logical Address** (Layer 3) used to identify a device across different networks. Unlike the MAC address, the IP address allows routing over the Internet.

### Format (IPv4)
*   **Length:** 32 bits (4 Bytes).
*   **Notation:** Dotted Decimal (e.g., `192.168.1.10`).
*   **Parts:**
    1.  **Net_ID:** Identifies the Network. All devices on the same LAN must have the same Net_ID.
    2.  **Host_ID:** Identifies the specific device *within* that network. Must be unique in the subnet.

---

## 2. IP Classes (Classful Addressing)
Historically, IP addresses were divided into fixed classes based on the value of the first octet.

| Class | First Octet Range | High Order Bits | Net_ID / Host_ID | Default Mask | Usage |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **A** | **1 - 126** | `0...` | N.H.H.H (/8) | 255.0.0.0 | Huge networks (ISPs, Governments) |
| **B** | **128 - 191** | `10...` | N.N.H.H (/16) | 255.255.0.0 | Medium to Large Orgs |
| **C** | **192 - 223** | `110...` | N.N.N.H (/24) | 255.255.255.0 | Small Networks (Home/Office) |
| **D** | **224 - 239** | `1110...` | N/A | N/A | **Multicast** |
| **E** | **240 - 255** | `1111...` | N/A | N/A | Experimental/Research |

> [!NOTE] **Missing 127?**
> The range `127.0.0.0` to `127.255.255.255` is reserved for **Loopback** testing.
> `127.0.0.1` (localhost) checks if your own computer's TCP/IP stack is working. It never sends traffic to the network.

---

## 3. Special Addresses
Within any network block, two addresses are **never** assigned to a device:

1.  **Network Address:** The very first address. All Host bits are `0`.
    *   Example: `192.168.1.0`. Identifies the wire/subnet itself.
2.  **Broadcast Address:** The very last address. All Host bits are `1`.
    *   Example: `192.168.1.255`. Used to shout to everyone in that subnet.

---

## 4. Configuration Rules
1.  **Unique Host_ID:** No two devices can have the same IP on the same network.
2.  **Matching Net_ID:** To communicate directly (without a router), devices must share the exact same Net_ID.
3.  **Router Requirement:** If Source Net_ID ≠ Dest Net_ID, you must send traffic to a **Default Gateway** (Router).

> [!TIP] **Configuration Check**
> If Device A is `192.168.1.5` and Device B is `192.168.2.5` (assuming Class C masks), they are on **different networks**. They cannot ping each other just by connecting a switch cable between them; a router is required.
