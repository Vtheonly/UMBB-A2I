
## 1. Definition of a Computer Network
A **Computer Network** is an interconnection of various computing entities (computers, servers, printers, phones) via communication media (cables, wireless waves) for the purpose of:
1.  **Exchanging information:** Data, voice, video, text messages.
2.  **Sharing resources:** Both hardware (printers, storage devices) and software (applications, files, databases).

> [!INFO] **Core Concept**
> Think of a network not just as computers hooked together, but as a system of **nodes** (devices) and **arcs** (links) designed to move data from Point A to Point B efficiently and reliably.

---

## 2. The Three Pillars of Communication
Regardless of the technology used (Fiber, Wi-Fi, 5G), every communication system requires three specific elements:

1.  **The Source (Sender):** The device that originates the message. It encodes the data (e.g., converting a JPG image into binary bits).
2.  **The Destination (Receiver):** The device that receives the message. It decodes the data back into a usable format.
3.  **The Channel (Medium):** The path over which the message travels. This can be physical (copper wire) or intangible (radio waves).

## 3. Network Elements: Terminology
A network is built using two main categories of equipment: **Terminal Devices** and **Intermediary Devices**, connected by **Media**.

### A. Terminal Devices (End Devices)
In technical terms, these are often called **DTE (Data Terminal Equipment)**.
*   **Role:** They are the interface between the human user and the underlying communication network. They are the **source** or **destination** of traffic.
*   **Examples:**
    *   Computers (Workstations, Laptops).
    *   Servers (File servers, Web servers).
    *   Network Printers.
    *   VoIP Phones.
    *   Smartphones/Tablets.
    *   Security Cameras.

### B. Intermediary Devices
These devices work "behind the scenes" to ensure data flows correctly. They connect end devices to the network or connect multiple networks together.
*   **Role:** Regenerate signals, steer traffic paths, and notify of errors.
*   **Key Devices:**
    *   **Hub (Concentrateur):** A "dumb" device. It blindly broadcasts data received on one port to *all* other ports. (Layer 1).
    *   **Switch (Commutateur):** A "smart" device. It filters and forwards data only to the specific destination device based on MAC address. (Layer 2).
    *   **Router:** Connects different networks (e.g., your LAN to the Internet). It uses IP addresses to determine the best path. (Layer 3).
    *   **Firewall:** Filters traffic based on security rules.

### C. Network Media (Connections)
The medium provides the channel for data transmission. The *encoding* of the signal depends on the medium type.

| Medium Type | Physical Form | Signal Encoding |
| :--- | :--- | :--- |
| **Copper** | Coaxial, Twisted Pair (RJ45) | **Electrical Impulses** |
| **Fiber Optic** | Glass or Plastic strands | **Light Pulses** (Lasers/LEDs) |
| **Wireless** | No physical cable | **Electromagnetic Waves** (Radio) |

> [!TIP] **Student Tip**
> Never confuse a **Switch** with a **Hub**.
> *   **Hub:** Broadcasting (sends to everyone). High collision risk. Legacy/Obsolete.
> *   **Switch:** Micro-segmentation (sends only to receiver). Efficient. Standard in modern LANs.
