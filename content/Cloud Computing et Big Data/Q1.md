> [!question] According to the core definition, Cloud Computing is best described not as a single technology, but as what?
> a) A localized server installation
> b) A consumption model for IT resources
> c) A proprietary hardware system
> d) A complex management protocol
>> [!success]- Answer
>> b) A consumption model for IT resources

> [!question] Which of the following is NOT listed as a configurable computing resource in the shared pool?
> a) Networks
> b) Servers
> c) Storage
> d) Physical Power Plants
>> [!success]- Answer
>> d) Physical Power Plants

> [!question] What characterizes the provisioning and release of resources in Cloud Computing?
> a) It requires significant service provider interaction.
> b) It involves a lengthy manual approval process.
> c) It can be done rapidly with minimal management effort.
> d) It requires physical hardware installation by the user.
>> [!success]- Answer
>> c) It can be done rapidly with minimal management effort.

> [!question] Who is responsible for hosting the infrastructure in a Cloud Computing model?
> a) The end-user
> b) The provider (e.g., AWS, Google, Azure)
> c) The local government
> d) The internet service provider (ISP) only
>> [!success]- Answer
>> b) The provider (e.g., AWS, Google, Azure)

> [!question] In terms of ownership, how does Cloud Computing differ from traditional IT?
> a) The user must own the hardware to use the software.
> b) The user does not need to own the hardware.
> c) Ownership is shared equally between all users.
> d) The user owns the servers but not the network.
>> [!success]- Answer
>> b) The user does not need to own the hardware.

> [!question] What does "On-Demand Usage" imply for the user?
> a) Users must reserve resources months in advance.
> b) Users consume resources exactly when they need them.
> c) Resources are always running, regardless of need.
> d) Users must physically go to the data center to access data.
>> [!success]- Answer
>> b) Users consume resources exactly when they need them.

> [!question] How can a user typically "spin up" a server in the Cloud context?
> a) By filing a written request form.
> b) By installing a local generator.
> c) With a click or an API call.
> d) By purchasing a new hard drive.
>> [!success]- Answer
>> c) With a click or an API call.

> [!question] How are Cloud services primarily delivered?
> a) Via physical disks sent by mail.
> b) Over a network, usually the public Internet.
> c) Through direct cable connection to the provider's HQ.
> d) Via local Bluetooth connections only.
>> [!success]- Answer
>> b) Over a network, usually the public Internet.

> [!question] Regarding installation, what is a key benefit of Cloud Computing?
> a) No complex local installation is required on the user's machine.
> b) Installation requires a certified technician to visit the site.
> c) Users must install the operating system on the provider's hardware.
> d) Complex installation is required but is free of charge.
>> [!success]- Answer
>> a) No complex local installation is required on the user's machine.
