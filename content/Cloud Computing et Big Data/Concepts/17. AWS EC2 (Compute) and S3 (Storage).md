
### 1. AWS EC2 (Elastic Compute Cloud)
*   **What is it?** It is a web service that provides **resizable compute capacity** in the cloud. Think of it as a **Virtual Server** you rent by the hour or second.
*   **Category:** It is the classic example of **IaaS** (Infrastructure as a Service).
*   **Function:** It gives you raw processing power (CPU) and memory (RAM). You choose the Operating System (e.g., Windows or Linux), and you have full administrative control (Root access).
*   **Why "Elastic"?** You can instantly increase or decrease the number of servers you are running based on traffic (Elasticity).

### 2. AWS S3 (Simple Storage Service)
*   **What is it?** It is an object storage service built to store and retrieve any amount of data from anywhere on the Internet.
*   **Category:** It is an **Infrastructure** component (Storage) often used alongside EC2.
*   **Function:** It stores files (photos, videos, backups, logs) like a massive hard drive in the sky, but accessible via a URL or API.
*   **Key Detail:** It is designed for 99.999999999% (11 nines) of durability, meaning it practically never loses data.

> [!NOTE] **The Connection**
> In a typical application:
> *   **EC2** does the thinking (running the code/website).
> *   **S3** does the remembering (storing the images/files).
