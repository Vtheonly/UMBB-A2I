# 3. Careers in Data Science

The term "Data Science" often refers to the field, but inside the field, there are distinct roles. Understanding the differences is vital for job applications and team structure.

## 3.1 Role Comparison Table

| Role | Focus | Primary Tools | Analogy |
| :--- | :--- | :--- | :--- |
| **Data Analyst** | **Descriptive:** What happened? Visualizing current data. | Excel, SQL, Tableau, PowerBI | The Historian/Journalist who reports the news. |
| **Data Scientist** | **Predictive:** What will happen? Modeling and Algorithms. | Python, R, Scikit-Learn, Stats | The Inventor who builds a crystal ball. |
| **Data Engineer** | **Infrastructure:** Building the pipelines that move data. | SQL, Spark, Hadoop, Cloud (AWS) | The Plumber/Architect who builds the water pipes so the water (data) flows. |
| **ML Engineer** | **Production:** Scaling models to run fast and reliable. | TensorFlow, Docker, Kubernetes | The Factory Manager who mass-produces the Inventor's prototype. |
| **Business Analyst** | **Translation:** Bridging technical and business teams. | SQL, Excel, PowerPoint | The Translator between the geeks and the CEO. |

---

## 3.2 Deep Dive into Roles

### Data Analyst
*   **Task:** Clean data, interpret trends, create dashboards.
*   **Example:** A dashboard showing hospital bed occupancy rates by week.

### Data Scientist
*   **Task:** Advanced statistics, hypothesis testing, building predictive models.
*   **Example:** An algorithm that predicts *which specific patient* will likely need an ICU bed next week.

### Data Engineer
*   **Task:** ETL (Extract, Transform, Load). Ensure data is available, reliable, and accessible.
*   **Example:** Building a pipeline that automatically pulls lab results every hour and stores them in a data warehouse for the Data Scientist to use.

### Machine Learning Engineer
*   **Task:** Optimization and deployment.
*   **Example:** Taking the Data Scientist's model (which runs slowly on a laptop) and optimizing it to run in milliseconds on a cloud server for millions of users.
