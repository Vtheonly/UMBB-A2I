
Here is a quick guide on which tool to pick based on the problem you are solving.

### Scenario A: "I need to find the index AND the item"
**Problem:** You are looping through a list of students, and you need to print their rank (1, 2, 3...) next to their name.
*   ❌ **Bad Way:** `range(len(students))`
*   ✅ **Good Way:** `enumerate()`

```python
students = ["Ali", "Sara", "Karim"]

# "i" gives you the index (0, 1, 2)
# "student" gives you the value
for i, student in enumerate(students, start=1):
    print(f"Rank {i}: {student}")
```

### Scenario B: "I need to combine two separate lists"
**Problem:** You have a list of `names` and a separate list of `grades`. You want to process them together as pairs.
*   ✅ **Good Way:** `zip()`

```python
names = ["Ali", "Sara"]
grades = [90, 85]

# Pairs them up: ("Ali", 90), ("Sara", 85)
for name, grade in zip(names, grades):
    print(f"{name} got {grade}")
```

### Scenario C: "I need to filter data based on a condition"
**Problem:** You have a list of prices, and you only want to keep the ones under $100.
*   ✅ **Good Way:** List Comprehension with `if`

```python
prices = [50, 150, 20, 300]
# [Result for Item in List if Condition]
cheap_items = [p for p in prices if p < 100]
# Result: [50, 20]
```

### Scenario D: "I need to remove duplicates"
**Problem:** You have a list of Customer IDs, but some customers appear multiple times. You just want the unique IDs.
*   ✅ **Good Way:** `set()`

```python
ids = [101, 102, 101, 103, 102]
unique_ids = list(set(ids))
# Result: [101, 102, 103] (Order is not guaranteed!)
```

### Scenario E: "I need to look up information instantly"
**Problem:** You have a student ID (12345) and you want to find their name immediately without looping through 10,000 rows.
*   ✅ **Good Way:** `dict` (Dictionary)

```python
# Slower (List): Python has to check every item one by one
students_list = [("123", "Ali"), ("456", "Sara")]

# Faster (Dictionary): Python jumps directly to the answer
students_dict = {"123": "Ali", "456": "Sara"}

name = students_dict["123"] # Instant result
```

### Scenario F: "I need to clean a dirty text file"
**Problem:** You read a file and every line has `\n` or weird spaces at the end, causing errors.
*   ✅ **Good Way:** `.strip()`

```python
raw_line = "  Laptop, 1000  \n"
clean = raw_line.strip() 
# Result: "Laptop, 1000" (Spaces inside remain, spaces outside gone)
```
