
# 7. Multivariate Analysis

Multivariate analysis looks at interactions between **three or more variables** simultaneously.

## 1. Pair Plots
This is a high-density visualization that plots pairwise relationships in a dataset.

```python
sns.pairplot(df, hue='species', diag_kind='kde', height=2.5)
```

**How to read it:**
*   **Diagonal:** Shows the univariate distribution (KDE or Histogram) of each variable, separated by the `hue` category.
*   **Off-Diagonal:** Scatter plots of Variable X vs Variable Y.
*   **Value:** It instantly highlights which features separate the classes best. (e.g., "Petal Length clearly separates Setosa from the others").

## 2. Facet Grids
Facet grids allow you to create a grid of plots based on a categorical variable. It is "Small Multiples" logic.

```python
g = sns.FacetGrid(df, col='species') # Create a grid, one plot per species
g.map_dataframe(sns.scatterplot, x='sepal_length', y='sepal_width')
```
*   *Use Case:* When you want to see if the correlation between X and Y changes depending on group Z. (e.g., "Is age correlated with salary differently for Men vs Women?").

## 3. Grouped Aggregations
Using Pandas `groupby` to analyze trends numerically across segments.

```python
# Group by species and calculate the mean of sepal_length
grouped = df.groupby('species')['sepal_length'].mean()
print(grouped)
```

You can visualize this aggregation with a simple bar plot to compare averages across groups.

```python
grouped.plot(kind='bar', color=['skyblue', 'lightgreen', 'salmon'])
plt.title('Average Sepal Length by Species')
plt.show()
```
