# 5. Univariate Analysis

**Univariate Analysis** focuses on visualizing and understanding **one variable at a time**.

## A. Numerical Variables
We want to see the distribution shape and detect outliers.

### 1. Histograms (Distribution)
Shows how frequently data points appear in specific ranges (bins).
*   **Use case:** Checking for Normality or Skewness.

```python
sns.histplot(data=df, x='sepal_length', kde=True)
plt.title('Sepal Length Distribution')
plt.show()
```
*   `kde=True`: Adds a Kernel Density Estimate line (smooth curve) over the bars.

### 2. Boxplots (Outliers & Spread)
The Boxplot is the visual representation of `df.describe()`.
*   **Box:** Represents the Interquartile Range (IQR) - the middle 50% of data.
*   **Line in Box:** The Median.
*   **Whiskers:** Extend to 1.5 * IQR.
*   **Points outside whiskers:** Outliers.

```python
sns.boxplot(x=df['sepal_length'])
plt.title('Sepal Length Boxplot')
plt.show()
```

---

## B. Categorical Variables
We want to see the frequency (count) of each category.

### 1. Bar Charts
The standard way to visualize categorical counts.

```python
# Using Pandas plotting backend
df['species'].value_counts().plot(kind='bar')
plt.title('Count of Species')
plt.xlabel('Species')
plt.ylabel('Count')
plt.show()
```

### 2. Pie Charts
> [!DANGER] **Avoid Pie Charts**
> Pie charts are generally discouraged in professional data analysis because human eyes are bad at comparing angles. Bar charts are almost always superior. If you must use one, use it only for < 5 categories.

---

## Summary of Univariate Actions
1.  **Numerical:** Run Histogram -> Check Skew -> Run Boxplot -> Check Outliers.
2.  **Categorical:** Run `value_counts()` -> Plot Bar Chart -> Check for class imbalance (e.g., one category has 90% of data).
