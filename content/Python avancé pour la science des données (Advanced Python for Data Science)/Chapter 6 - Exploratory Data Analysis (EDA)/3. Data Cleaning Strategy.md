# 3. Data Cleaning Strategy

Real-world data is rarely clean. This phase is about handling missing values, duplicates, and inconsistencies.

## Handling Duplicates
Duplicate rows can bias your analysis (e.g., inflating the count of a specific class).

### Detection
```python
# Returns True/False for every row
df.duplicated()

# Sum them up to see total duplicate rows
count = df.duplicated().sum()
print(f"Number of duplicate rows: {count}")
```

### Removal
```python
# Removes duplicates in place or returns a new df
df_clean = df.drop_duplicates()
```
> [!WARNING] **Context Matters**
> In transactional data (e.g., store purchases), two rows might look identical (Same item, same price, same time) but represent two different customers buying the same thing. Only drop duplicates if the row represents a unique entity ID or if you are sure they are errors.

---

## Handling Missing Values
Missing data is represented as `NaN` (Not a Number) or `None`.

### Detection
```python
# Check total missing values per column
df.isnull().sum()
```

### Treatment Strategies
Once you identify missing values, you have three main options:

1.  **Drop (Removal):**
    *   *When to use:* If the missing data is minimal (< 5% of rows) or if the column is mostly empty (> 50% missing).
    *   *Code:* `df.dropna()`

2.  **Impute (Filling):**
    *   *When to use:* You want to preserve the rows.
    *   *Method:* Fill with the **Mean** (for normal distribution), **Median** (if outliers exist), or **Mode** (for categorical data).
    *   *Code:* `df['col'].fillna(df['col'].mean())`

3.  **Interpolate:**
    *   *When to use:* Time-series data where values are related to previous time steps.

## Checking Unique Values
For categorical columns (type `object`), you need to know how many distinct categories exist.

```python
# Count distinct values
df['species'].nunique()

# See the actual values and their counts
df['species'].value_counts()
```

**Why `value_counts` is powerful:**
*   It detects **Cardinality**: Are there too many categories? (e.g., 500 cities).
*   It detects **Rare Labels**: Is there a category that only appears once?
*   It detects **Typographical Errors**: Do you see 'Apple', 'apple', and 'Aplle'? These need to be merged.
