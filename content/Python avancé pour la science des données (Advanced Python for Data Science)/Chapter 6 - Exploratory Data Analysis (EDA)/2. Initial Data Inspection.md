# 2. Initial Data Inspection

Before calculating complex statistics, you must visually inspect the raw dataframe to catch obvious errors (like bad file parsing).

## Loading the Data
For this module, we utilize the classic `iris` dataset, which contains measurements of iris flowers.

```python
df = sns.load_dataset('iris')
```

## Basic Inspection Commands

### 1. Shape of Data
Check how much data you have.
```python
df.shape
# Output: (150, 5) -> 150 Rows, 5 Columns
```
*   **Rows:** Number of observations/samples.
*   **Columns:** Number of features/variables.

### 2. Previewing Data
Never print the whole dataset. Use `head()` and `tail()` to see the structure.

```python
df.head() # Shows first 5 rows
df.tail() # Shows last 5 rows
```
> [!NOTE] **Why check `tail()`?**
> `head()` looks fine, but sometimes datasets have footer information, "Grand Totals", or corrupted lines at the very end of the file. Checking `tail()` saves you from errors later.

### 3. Column Data Types and Info
This is arguably the most important initial step. You need to verify that Python interpreted your data correctly.

```python
df.info()
```

**What to look for in `df.info()` output:**
1.  **`RangeIndex`:** Confirms the number of rows.
2.  **`Non-Null Count`:** Tells you immediately if you have missing data. If you have 150 entries but a column says "130 non-null", you have 20 missing values.
3.  **`Dtype`:**
    *   `float64`: Decimal numbers.
    *   `int64`: Whole numbers.
    *   `object`: Usually text/strings (categorical data).

### 4. Listing Columns
If you have a dataset with 100+ columns, `df.columns` helps you copy-paste names exactly (avoiding spelling errors).
```python
df.columns
```

## Validating Data Types
A common issue in EDA is **Data Type Mismatch**.

*   **Scenario:** A column "Price" contains `"$100"`.
*   **Pandas Result:** It loads as `object` (string) because of the `$` symbol.
*   **Problem:** You cannot calculate the mean or sum of strings.
*   **Solution:** You must clean the symbols and convert the type to float.

**Checklist for Types:**
*   Are dates actually `datetime` objects or strings?
*   Are categorical codes (0, 1) loaded as integers or categories?
*   Are numbers loaded as strings?
