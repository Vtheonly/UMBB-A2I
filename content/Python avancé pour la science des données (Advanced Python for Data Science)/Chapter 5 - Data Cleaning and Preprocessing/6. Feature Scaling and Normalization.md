
# 6. Feature Scaling and Normalization

## Why Scale Data?
Datasets often contain features with vastly different magnitudes.
*   Age: 20 to 80
*   Income: 20,000 to 1,000,000

Many algorithms (KNN, SVM, Gradient Descent, Neural Networks) calculate **Euclidean Distance**. If one feature has a range in the millions and another in the tens, the larger feature will dominate the distance calculation, making the smaller feature irrelevant. Scaling puts all features on a level playing field.

> [!NOTE] **Algorithms that don't need scaling**
> Tree-based models (Random Forest, Decision Trees, XGBoost) are generally invariant to scaling because they make cuts based on value thresholds, not distances.

---

## 1. Min-Max Scaling
*   **Concept:** Rescales data to a fixed range, usually $[0, 1]$.
*   **Formula:** $$x' = \frac{x - x_{min}}{x_{max} - x_{min}}$$
*   **Pros:** Preserves the shape of the original distribution.
*   **Cons:** **Highly sensitive to outliers.** If $x_{max}$ is an extreme outlier, normal data gets squashed into a tiny range near 0.
*   **Use:** Neural Networks, Image Data.

## 2. Standardization (Z-Score Scaling)
*   **Concept:** Centers data around Mean ($0$) with a Standard Deviation of $1$.
*   **Formula:** $$x' = \frac{x - \mu}{\sigma}$$
*   **Pros:** Handles outliers better than Min-Max (doesn't squash data as much).
*   **Cons:** Assumes data is roughly Gaussian (Bell Curve).
*   **Use:** Logistic Regression, SVM, Linear Regression.

## 3. Robust Scaling
*   **Concept:** Similar to Standardization but uses statistics that are robust to outliers (Median and IQR).
*   **Formula:** $$x' = \frac{x - median}{IQR}$$
*   **Pros:** The best choice if your data contains significant **outliers**.

---

## 4. Normalization (L1 & L2 Norms)
Unlike the scalers above (which scale *columns*), Normalization typically scales individual *rows* (vectors) to have a unit norm.

### L2 Normalization (Euclidean Norm)
*   **Concept:** Scales the vector so its length (magnitude) is 1. The data is projected onto the "Unit Circle."
*   **Formula:** Divide each element by $\sqrt{x_1^2 + x_2^2 + ...}$
*   **Application:** Crucial for **Cosine Similarity**, Text Clustering, and search engines.

### L1 Normalization (Manhattan Norm)
*   **Concept:** Scales the vector so the sum of absolute values is 1.
*   **Application:** Sparse data, text analysis (TF-IDF).

---

## Summary: Which to Choose?

| Scenario | Recommended Method |
| :--- | :--- |
| **Standard default** | **Standardization (StandardScaler)** |
| **Bounded range required [0,1]** | **Min-Max Scaler** |
| **Many Outliers present** | **Robust Scaler** |
| **Calculating Similarity (Text/Clustering)** | **L2 Normalization** |
