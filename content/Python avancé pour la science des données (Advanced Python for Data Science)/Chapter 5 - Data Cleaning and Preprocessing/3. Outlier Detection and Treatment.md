# 3. Outlier Detection and Treatment

## What are Outliers?
Outliers are extreme values that deviate significantly from the rest of the observations.
*   **Valid Outliers:** True extreme events (e.g., Elon Musk's income).
*   **Invalid Outliers:** Data errors (e.g., Age = 200).

They distort statistical measures (Mean and Standard Deviation are highly sensitive to outliers) and confuse ML models (especially linear regression).

---

## 1. Detection Methods

### A. Visualization (Boxplot)
The most intuitive method.
*   **Box:** Represents the Interquartile Range (IQR) - the middle 50% of data.
*   **Whiskers:** Extend to non-outlier data.
*   **Points:** Individual dots outside the whiskers are outliers.

### B. Z-Score (Standard Score)
*   **Concept:** Measures how many standard deviations ($\sigma$) a data point ($x$) is away from the mean ($\mu$).
*   **Formula:** $$z = \frac{x - \mu}{\sigma}$$
*   **Threshold:** Generally, if $|z| > 3$, the point is an outlier.
*   **Assumption:** Works best if data is **Normally Distributed** (Bell Curve).

### C. IQR Method (Robust)
*   **Concept:** Uses quartiles, making it robust against extreme values itself.
*   **Steps:**
    1.  Calculate $Q1$ (25th percentile) and $Q3$ (75th percentile).
    2.  Calculate $IQR = Q3 - Q1$.
    3.  Define bounds:
        *   **Lower Bound:** $Q1 - 1.5 \times IQR$
        *   **Upper Bound:** $Q3 + 1.5 \times IQR$
    4.  Any value outside these bounds is an outlier.

---

## 2. Handling Strategies

Once detected, do not blindly delete outliers. Context matters.

### Option 1: Removal (Trimming)
*   **Action:** Delete the rows containing outliers.
*   **When to use:** If the outlier is clearly a data error (e.g., human height = 3 meters), or if the dataset is huge and losing a few rows doesn't matter.

### Option 2: Capping (Winsorization)
*   **Action:** Replace values exceeding the limits with the limit value itself.
    *   Example: If Upper Bound is 100, and a value is 150, replace 150 with 100.
*   **When to use:** When you want to keep the data point but reduce its influence on the model.

### Option 3: Transformation
*   **Action:** Apply a mathematical function to compress the range of data.
*   **Log Transformation (`np.log`):** Great for right-skewed data (e.g., Income, House Prices). It pulls extreme large values closer to the center.

### Option 4: Imputation
*   **Action:** Treat the outlier as "missing data" and replace it with the median.

### Summary Code Snippet
```python
# IQR Method Calculation
Q1 = df['Income'].quantile(0.25)
Q3 = df['Income'].quantile(0.75)
IQR = Q3 - Q1

lower_limit = Q1 - 1.5 * IQR
upper_limit = Q3 + 1.5 * IQR

# Filtering (Removal)
df_clean = df[(df['Income'] >= lower_limit) & (df['Income'] <= upper_limit)]

# Capping (Winsorization) using numpy
import numpy as np
df['Income_Capped'] = np.where(df['Income'] > upper_limit, upper_limit,
                      np.where(df['Income'] < lower_limit, lower_limit, df['Income']))
