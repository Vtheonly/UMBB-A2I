# 2. Pandas: Python Data Analysis Library

**Pandas** is built on top of NumPy. While NumPy is for numerical matrices, Pandas is for **Tabular Data** (like Excel or SQL tables) with heterogeneous types (text, numbers, dates).

## 2.1. Core Data Structures

### 2.1.1. Series (1D)
A labeled array. Think of it as a single column in Excel or a specialized Dictionary.
*   Has **Values** and an **Index**.

```python
s = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
```

### 2.1.2. DataFrame (2D)
A table of data containing rows and columns.
*   Each column is a `Series`.
*   Rows share an Index.
*   Columns have names.

## 2.2. Inspecting Data

The first step in any analysis is understanding what you have.

```python
df.head(n)      # First n rows
df.tail(n)      # Last n rows
df.info()       # Index, DataType, Memory, Non-Null counts (Crucial for missing data)
df.describe()   # Summary stats (mean, min, max, 25%, 50%, 75%) for numeric cols
df.shape        # (rows, columns)
df.columns      # List of column names
df.dtypes       # Data type of each column
```

## 2.3. Selection and Indexing

This is often confusing. Pandas offers three primary ways to select data:

### 2.3.1. `[]` Operator (Bracket notation)
*   `df['Column']`: Selects a column (returns Series).
*   `df[['Col1', 'Col2']]`: Selects multiple columns (returns DataFrame).
*   `df[0:5]`: Slices rows by integer position.

### 2.3.2. `.loc` (Label-based)
Selects by **Name/Label**.
*   Syntax: `df.loc[row_label, col_label]`
*   **Crucial:** The stop bound is **inclusive**. `df.loc[0:2]` returns rows 0, 1, **and 2**.

### 2.3.3. `.iloc` (Integer-based)
Selects by **Index Position** (0 to N-1).
*   Syntax: `df.iloc[row_pos, col_pos]`
*   **Crucial:** The stop bound is **exclusive** (like standard Python). `df.iloc[0:2]` returns rows 0 and 1.

> [!TIP]
> Use `.at[]` and `.iat[]` if you only need to access a **single scalar value**. They are much faster than `loc` and `iloc`.

## 2.4. Cleaning Data

Real-world data is messy.

*   **Missing Data:**
    *   `df.isnull().sum()`: Count missing values per column.
    *   `df.dropna()`: Remove rows with NaNs.
    *   `df.fillna(value)`: Replace NaNs with a specific value (e.g., mean or 0).
*   **Duplicates:**
    *   `df.drop_duplicates()`: Removes duplicate rows.

## 2.5. Filtering (Conditional Selection)

Similar to NumPy boolean masking.

```python
# 1. Standard Boolean Indexing
high_salary = df[df['Salary'] > 50000]

# 2. Multiple Conditions (Must use parentheses & bitwise operators)
# & for AND, | for OR
subset = df[(df['Age'] > 25) & (df['City'] == 'Algiers')]

# 3. Query Method (Cleaner syntax)
subset = df.query('Age > 25 and City == "Algiers"')
```

## 2.6. Data Transformation

Modifying values in columns.

*   **`apply(func)`**: Applies a function to an entire axis (row or column). Flexible but slower.
*   **`map(dict)`**: Used on Series to map values (e.g., `{'M': 0, 'F': 1}`).
*   **`astype(type)`**: Converts data types (e.g., string to float).

## 2.7. Grouping & Aggregation (`groupby`)

This implements the "Split-Apply-Combine" strategy.

```python
# Group by 'City' and calculate mean of other columns
df.groupby('City').mean()

# Specific aggregation on specific columns
df.groupby('City').agg({
    'Salary': 'max',
    'Age': 'mean'
})
```

## 2.8. Merging and Concatenation

*   **`pd.concat([df1, df2])`**: Stacks DataFrames on top of each other (axis=0) or side-by-side (axis=1). Simple stacking.
*   **`pd.merge(df1, df2, on='Key', how='inner')`**: Database-style join.
    *   `how='inner'`: Intersection of keys.
    *   `how='left'`: Keep all keys from left DF.
    *   `how='outer'`: Keep all keys from both.

## 2.9. Reshaping (Pivot & Melt)

Crucial for preparing data for visualization.

### 2.9.1. `pivot_table` (Long to Wide)
Summarizes data (like Excel Pivot Tables). Handles duplicate entries by aggregating them.
```python
df.pivot_table(index='City', columns='Year', values='Sales', aggfunc='sum')
```

### 2.9.2. `melt` (Wide to Long)
Unpivots data. Turns columns into rows. This is the **Tidy Data** format required by Seaborn.
```python
# id_vars: columns to keep
# value_vars: columns to unpivot
pd.melt(df, id_vars=['Date'], value_vars=['Apple_Sales', 'Banana_Sales'])
```

## 2.10. Time Series
Pandas was originally built for financial time series.
*   `pd.to_datetime()`: Converts strings to Timestamp objects.
*   `dt` accessor: Access components (e.g., `df['Date'].dt.year`).
