# 4. Seaborn: High-Level Statistical Data Visualization

**Seaborn** is built on top of Matplotlib.
*   It provides beautiful default styles.
*   It works seamlessly with **Pandas DataFrames**.
*   It handles statistical aggregation automatically (e.g., calculating mean and error bars).

## 4.1. The Seaborn Workflow

1.  **Prepare Data:** Ensure data is in a Pandas DataFrame, preferably in "Long/Tidy" format.
2.  **Set Aesthetics:** Use themes.
3.  **Plot:** Call the Seaborn function.
4.  **Customize:** Use Matplotlib functions to tweak the result (since Seaborn returns Matplotlib objects).

```python
import seaborn as sns
import matplotlib.pyplot as plt

# 1. Setup Theme
sns.set_theme(style="whitegrid", palette="pastel")

# 2. Plot
sns.scatterplot(data=df, x="total_bill", y="tip", hue="sex")

# 3. Show
plt.show()
```

## 4.2. Key Syntax Structure

Most Seaborn functions share this signature:

```python
sns.function(
    data=df,        # The DataFrame
    x="col_name",   # Column for X axis
    y="col_name",   # Column for Y axis
    hue="col_name", # Column for coloring (adds 3rd dimension/category)
    style="col_name", # Different marker shapes per category
    size="col_name"   # Different marker sizes
)
```

## 4.3. Plot Categories

### 4.3.1. Relational Plots (Variables Relationship)
*   **`sns.scatterplot()`**: Points. Good for correlations.
*   **`sns.lineplot()`**: Lines. Good for time series. Draws confidence intervals (shadow) by default if there are multiple values per x-point.

### 4.3.2. Distribution Plots (How data is spread)
*   **`sns.histplot()`**: Histogram.
*   **`sns.kdeplot()`**: Kernel Density Estimate (Smooth curve of distribution).
*   **`sns.boxplot()`**: Shows quartiles, median, and outliers. **Essential for spotting outliers.**

### 4.3.3. Matrix Plots
*   **`sns.heatmap()`**: Grid of colors.
    *   **Best Use:** Visualizing a Correlation Matrix (`df.corr()`).
    *   *Tip:* Set `annot=True` to see the numbers in the squares.

```python
corr = df.corr()
sns.heatmap(corr, annot=True, cmap='coolwarm')
```

> [!TIP]
> **The `hue` Parameter**
