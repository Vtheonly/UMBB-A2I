# 5. Plotly & Basemap: Specialized Visualization

## 5.1. Plotly: Interactive Visualization

Unlike Matplotlib (static images), **Plotly** creates interactive web-based plots.
*   **Features:** Zoom, Pan, Hover tooltips.
*   **Module:** `plotly.express` (px) is the high-level interface (similar to Seaborn).

### 5.1.1. Basic Syntax
```python
import plotly.express as px

fig = px.scatter(
    df, 
    x='total_bill', 
    y='tip', 
    color='sex',           # Like 'hue' in Seaborn
    size='size',           # Bubble size
    hover_data=['time']    # Extra info on hover
)
fig.show()
```

> [!NOTE]
> Plotly plots are rendered as HTML/JavaScript. They are perfect for Dashboards.

## 5.2. Basemap (Legacy Geospatial)

**Basemap** is a toolkit for Matplotlib to plot 2D maps.
*   **Status:** **Deprecated** in favor of *Cartopy*, but still used in legacy code.
*   **Concept:** It projects the spherical earth onto a 2D plane.

### 5.2.1. Workflow
1.  **Create Basemap Object:** Define the projection (e.g., 'merc' for Mercator) and lat/lon boundaries.
2.  **Draw Features:** Coastlines, countries, rivers.
3.  **Plot Data:** Convert real-world Lat/Lon to x/y map coordinates before plotting.

```python
from mpl_toolkits.basemap import Basemap
import matplotlib.pyplot as plt

# 1. Setup Projection
m = Basemap(projection='merc', llcrnrlat=-80, urcrnrlat=80, ...)

# 2. Draw
m.drawcoastlines()
m.fillcontinents()

# 3. Plot a point (Convert Coords first!)
x, y = m(lon, lat) # Converts Longitude/Latitude to Map X/Y
m.scatter(x, y, color='red')
```
