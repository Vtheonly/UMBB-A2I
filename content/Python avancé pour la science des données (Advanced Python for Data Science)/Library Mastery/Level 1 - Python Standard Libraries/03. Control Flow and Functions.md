# 3. Control Flow and Functions

## 3.1. Logic and "Truthiness"
In Python, conditional checks (`if`) rely on boolean logic. However, Python has a concept called **Truthiness**: non-boolean values can evaluate to True or False.

**Falsy Values (Evaluate to False):**
*   `False`, `None`, `0`, `0.0`
*   Empty sequences: `""` (String), `[]` (List), `()` (Tuple), `{}` (Dict)

**Truthy Values:**
*   Everything else.

```python
# Professional way to check if a list is empty
my_list = []
if not my_list:
    print("List is empty") 
```

## 3.2. Loops: `for` and `while`

### The `for` Loop & `range()`
The `for` loop iterates over any sequence.
`range(start, stop, step)` generates numbers lazily (it doesn't store them all in memory).

### Loop Control
*   **`break`**: Exits the loop immediately.
*   **`continue`**: Skips the rest of the current iteration and starts the next one.
*   **`pass`**: Does nothing (placeholder).

### List Comprehensions
A Pythonic way to create lists. It is more concise and often faster than a loop.

```python
# Standard Loop
squares = []
for x in range(10):
    if x % 2 == 0:
        squares.append(x**2)

# List Comprehension
# Syntax: [expression FOR item IN iterable IF condition]
squares = [x**2 for x in range(10) if x % 2 == 0]
```

## 3.3. Functions

### Basics
*   **Parameters:** Variables listed in the function definition.
*   **Arguments:** Real values passed to the function.
*   **`return`:** If a function doesn't return anything, it implicitly returns `None`.

### `*args` and `**kwargs`
Used when you don't know how many arguments will be passed.
*   `*args` (Non-Keyword Arguments): Passed as a **tuple**.
*   `**kwargs` (Keyword Arguments): Passed as a **dictionary**.

```python
def super_func(*args, **kwargs):
    print(f"Positional: {args}") # (1, 2, 3)
    print(f"Keywords: {kwargs}")   # {'name': 'Ali'}

super_func(1, 2, 3, name="Ali")
```

## 3.4. Generators (`yield`)
> [!TIP] **Memory Optimization**
> When processing massive datasets (e.g., 1 million rows), never load them all into a list. Use a Generator.

A function with `yield` pauses its execution and saves its state. It returns one item at a time.

```python
def my_generator():
    yield 1
    yield 2
    yield 3

# Usage
gen = my_generator()
print(next(gen)) # 1
print(next(gen)) # 2
# It remembers where it left off!
```
