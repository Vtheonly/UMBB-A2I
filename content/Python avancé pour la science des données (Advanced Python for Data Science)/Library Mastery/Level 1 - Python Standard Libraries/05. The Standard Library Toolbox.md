# 5. The Standard Library Toolbox

Python comes with "batteries included." Before installing external packages, you should master these built-in modules. They are optimized, reliable, and available everywhere.

## 5.1. File System Interaction: `os` & `sys`

### The `os` Module
Used for interacting with the Operating System (files, folders, paths).

```python
import os

# Best Practice: Path Joining
# Windows uses "\", Linux uses "/". os.path.join handles this automatically.
path = os.path.join("data", "raw", "file.csv")

# Checking existence
if os.path.exists(path):
    print("Found it!")

# Creating directories (safely)
os.makedirs("output/figures", exist_ok=True)
```

### The `sys` Module
Used for interacting with the Python Runtime.
*   `sys.path`: The list of directories Python searches for imports.
*   `sys.argv`: Access command-line arguments passed to the script.

## 5.2. File I/O: `json` & `csv`

### Context Managers (`with`)
> [!WARNING] **Always use `with`**
> Opening files without closing them causes memory leaks and data corruption. The `with` statement automatically closes the file, even if the code crashes.

### JSON (JavaScript Object Notation)
The standard format for web data. It looks exactly like a Python Dictionary.

```python
import json

data = {"name": "Ali", "score": 90}

# Writing
with open("data.json", "w") as f:
    json.dump(data, f)

# Reading
with open("data.json", "r") as f:
    loaded_data = json.load(f)
```

## 5.3. Math & Randomness

### `random`
*   `random.randint(a, b)`: Integer between a and b (inclusive).
*   `random.choice(list)`: Pick a random element.
*   `random.seed(x)`: Makes randomness reproducible (essential for Data Science experiments).

### `math`
*   Standard mathematical functions: `math.sqrt`, `math.log`, `math.pi`.
*   *Note:* For arrays/matrices, use `numpy` instead of `math`.

## 5.4. Dates: `datetime`
Handling time is notoriously difficult. This module standardizes it.

```python
from datetime import datetime

# Current time
now = datetime.now()

# Formatting (Date to String)
print(now.strftime("%Y-%m-%d")) # "2023-10-05"

# Parsing (String to Date)
date_obj = datetime.strptime("2023-10-05", "%Y-%m-%d")
```

## 5.5. Error Handling: `try`, `except`
Good code anticipates failure (e.g., missing files, bad internet).

```python
try:
    # Risky code
    result = 10 / 0
except ZeroDivisionError:
    # Backup plan
    print("Cannot divide by zero!")
except Exception as e:
    # Generic catch-all (use sparingly)
    print(f"Unknown error: {e}")
finally:
    # Runs no matter what (cleanup)
    print("Execution complete.")
```
