
## 1. Merging (Joining)
Combines two DataFrames based on a shared Key (ID).

```python
pd.merge(left_df, right_df, on='UserID', how='inner')
```

| Join Type (`how`) | Visual Logic | Result |
| :--- | :--- | :--- |
| **Inner** | Intersection | Keep only IDs found in **BOTH**. |
| **Outer** | Union | Keep IDs from **EITHER**. Fill missing with NaN. |
| **Left** | Left Side Priority | Keep all Left IDs. Attach Right info if it exists. |

## 2. Concatenation (Stacking)
Glues DataFrames together physically.
*   **`axis=0` (Vertical):** Adds more rows. (e.g., Combining Jan_Data and Feb_Data).
*   **`axis=1` (Horizontal):** Adds more columns. (Risky if indexes don't match perfectly).

## 3. Reshaping

### Melt (Wide -> Long)
Unpivots a table. Turns headers into column values. useful for machine learning libraries.
```python
# Turns columns [Jan, Feb, Mar] into a single column "Month"
df.melt(id_vars='Product', var_name='Month', value_name='Sales')
```

### Transpose (`.T`)
Swaps rows and columns instantly.
```python
df_transposed = df.T
```
