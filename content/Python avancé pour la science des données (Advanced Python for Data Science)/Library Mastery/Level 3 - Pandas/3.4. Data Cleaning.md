# 3.4. Data Cleaning

Real-world data is dirty. This phase is 80% of the job.

## 1. Handling Missing Data (NaN)
Pandas represents missing data as `NaN` (Not a Number) or `None`.

### Detection
```python
df.isnull().sum() # Returns count of missing values per column
```

### Removal (`dropna`)
*   `df.dropna(axis=0)`: Drop **rows** containing any NaN.
*   `df.dropna(axis=1)`: Drop **columns** containing any NaN.
*   `df.dropna(subset=['Age'])`: Drop rows only if 'Age' is missing.

### Imputation (`fillna`)
Filling missing data with a logical estimate.
```python
# Fill with a static number
df['Discount'].fillna(0, inplace=True)

# Fill with the mean (Average)
mean_age = df['Age'].mean()
df['Age'].fillna(mean_age, inplace=True)
```

## 2. String Manipulation (`.str`)
To clean text, you must access the `.str` attribute.

```python
# Clean whitespace and convert to lowercase
df['City'] = df['City'].str.strip().str.lower()

# Check for substring
mask = df['Email'].str.contains('gmail')

# Splitting columns
# "John Doe" -> ["John", "Doe"]
df['Name'].str.split(' ') 
```

## 3. Data Type Repair
Often, numbers load as strings ("1,000" or "$50") or errors exist ("Null").

```python
# 1. Remove bad characters
df['Price'] = df['Price'].str.replace('$', '')

# 2. Convert to numeric
# errors='coerce' turns unparseable strings into NaN (instead of crashing)
df['Price'] = pd.to_numeric(df['Price'], errors='coerce')

# 3. Convert to Datetime
df['Date'] = pd.to_datetime(df['Date'])
```

## 4. Replacing Specific Values
The `replace` method is powerful for standardizing categories.
```python
# Fix inconsistent naming
df['Gender'].replace(['Fem', 'F'], 'Female', inplace=True)

# Replace string 'none' with actual NaN object
import numpy as np
df.replace('none', np.nan, inplace=True)
```
