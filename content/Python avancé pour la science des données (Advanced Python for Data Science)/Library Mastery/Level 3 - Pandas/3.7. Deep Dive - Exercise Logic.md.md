## 1. The "Monthly Sales" Problem
**Goal:** Find the best month for sales and the best selling product.

### Step A: Handling Dates
The raw date is often a string ("04/19/19"). We need the Month.
*   **Bad Way:** String splitting `x.split('/')[0]`. Slow and brittle.
*   **Pro Way:** Convert to datetime, then use accessor.
    ```python
    df['Date'] = pd.to_datetime(df['Date'])
    df['Month'] = df['Date'].dt.month
    ```

### Step B: The Aggregation
To find the best month, we cannot just look at the table. We must group.
```python
results = df.groupby('Month').sum()
```
*   *Why sum?* Because we want total revenue, not average order value.

### Step C: The "Best" Month
*   **Visual:** `plt.bar(results.index, results['Sales'])`
*   **Programmatic:** `results['Sales'].idxmax()` gives the month number.

## 2. The "Medical Data" Problem
**Goal:** Clean a messy dataset containing 'NaN', 'none', and average calculations.

### Step A: The "None" Trap
The dataset contained the string `"none"` mixed with real data.
*   `df.isnull().sum()` FAILED to catch this because `"none"` is a valid string, not a Null object.
*   **Fix:** `df.replace(['none', 'nan'], np.nan, inplace=True)`

### Step B: Calculating Averages on Rows
We needed the average of 4 specific columns for each patient.
```python
cols = ['a', 'b', 'c', 'd']
df['average'] = df[cols].mean(axis=1)
```
*   **Crucial:** `axis=1` means "Move across the columns" (calculate for the row).
*   If you forget `axis=1`, it calculates the average of the column (vertically), which is wrong for this context.

### Step C: Filtering Outliers
We wanted to remove patients with extremely high blood pressure.
```python
# Keep only rows where BP is less than or equal to 120
df = df[ df['BloodPressure'] <= 120 ]
```
*   *Note:* This effectively drops the high rows. If we wanted to keep them but cap the value, we would use `.loc` assignment or `np.where`.
