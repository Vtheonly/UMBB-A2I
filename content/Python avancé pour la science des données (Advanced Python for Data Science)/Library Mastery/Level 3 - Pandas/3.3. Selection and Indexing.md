# 3.3. Selection and Indexing

This is where 90% of Pandas errors happen. You must distinguish between **Labels** and **Positions**.

## 1. Column Selection
*   **Series:** `df['Column']` (Returns 1D Series).
*   **DataFrame:** `df[['Column']]` (Returns 2D DataFrame - note double brackets).

## 2. The `loc` vs `iloc` Battle

| Feature | `.loc` (Label Based) | `.iloc` (Integer Position Based) |
| :--- | :--- | :--- |
| **Input** | Column/Row **Names** | Row/Col **Numbers** (0, 1, 2...) |
| **Slicing** | **INCLUSIVE** (Stop is included) | **EXCLUSIVE** (Stop is excluded) |
| **Example** | `df.loc['row1':'row5']` | `df.iloc[0:5]` |

### Examples
```python
# loc: "Give me rows 'Jan' through 'Mar', column 'Sales'"
df.loc['Jan':'Mar', 'Sales'] 
# Result: Includes Jan, Feb, AND Mar.

# iloc: "Give me rows 0 to 3, columns 0 to 2"
df.iloc[0:3, 0:2]
# Result: Includes rows 0, 1, 2 (Standard Python slicing rules).
```

> [!WARNING] **The Ambiguity of Integer Indexes**
> If your DataFrame has an index that is numbers (e.g., User IDs: 100, 101, 102), `df[100]` usually fails.
> *   Always use `.loc[100]` to mean "Label 100".
> *   Always use `.iloc[100]` to mean "The 100th row".

## 3. Boolean Indexing (Filtering)
Filtering creates a "Mask" (a Series of True/False) and overlays it on the DataFrame.

```python
# 1. Create Condition
mask = (df['Age'] > 25) & (df['Department'] == 'Sales')

# 2. Apply Mask
filtered_df = df[mask]
```

> [!DANGER] **Syntax Rules**
> 1.  You **must** use parentheses `()` around every condition.
> 2.  You **must** use bitwise operators: `&` (AND), `|` (OR), `~` (NOT).
> 3.  Python's `and` / `or` keywords **do not work** here.

## 4. The Query Method
A cleaner alternative found in advanced quizzes.
```python
df.query('Age > 25 and Department == "Sales"')
```
*   **Pros:** Readable, uses standard `and`/`or`, handles quotes well.
*   **Cons:** Slightly slower on massive datasets.
