# 3.2. Inspection and Basics

Before you analyze data, you must understand its "shape" and health.

## 1. Structural Inspection

| Command | Type | Description | Critical Note |
| :--- | :--- | :--- | :--- |
| `df.shape` | Attribute | Returns `(rows, cols)`. | No parentheses `()`! |
| `df.columns` | Attribute | Returns list of column names. | Useful for copying/pasting names. |
| `df.info()` | Method | Shows Dtypes & Non-Null counts. | **Best way to spot missing data.** |
| `df.head(n)` | Method | First `n` rows. | |
| `df.tail(n)` | Method | Last `n` rows. | **Crucial:** Checks for footer garbage or corrupted files. |
| `df.sample(n)`| Method | Random `n` rows. | Better than `head` for seeing variety in data. |

> [!NOTE] **Count vs. Size**
> *   `df.size`: Total number of cells (Rows × Cols). Includes NaNs.
> *   `df.count()`: Counts only **Valid (Non-Null)** values.

## 2. Statistical Summaries

### `df.describe()`
Provides a quick statistical overview.
*   **Default:** Only summarizes **Numeric** columns.
*   **Trick:** Use `df.describe(include='all')` to get stats on Strings (Count, Unique, Top, Freq).

### `df.value_counts()`
The most important function for **Categorical** data.
```python
df['Department'].value_counts()
# Sales       50
# IT          30
# HR          20
```
*   **Tip:** Use `normalize=True` to see percentages (e.g., Sales = 0.5) instead of raw counts.

### `df.corr()`
Generates a correlation matrix (-1 to 1) for all numeric columns.
*   **1.0:** Perfect positive correlation.
*   **-1.0:** Perfect negative correlation.
*   **0:** No linear relationship.
