# 2.1. NumPy Core and Memory Architecture

**NumPy** (Numerical Python) is the bedrock of the Python Data Science stack. It provides the **`ndarray`** (N-dimensional array), a structure that replaces Python's flexible but slow lists with high-performance, fixed-type arrays.

## 1. The "Why": Memory Architecture & Speed

Why do we need NumPy if Python already has Lists? The answer lies in how data is stored in memory.

### Python Lists (Heterogeneous & Scattered)
A Python list like `[1, "A", 3.5]` is an array of **pointers**. 
* **Overhead:** Each pointer links to a full Python Object scattered elsewhere in memory. Every integer object carries heavy overhead (type info, reference counts).
* **Access Speed:** To calculate `List[0] + List[1]`, the CPU must fetch the pointer, look up the object type, find the value, and then add. This is extremely slow for large datasets.

### NumPy Arrays (Homogeneous & Contiguous)
A NumPy array like `[1, 2, 3]` is a **single contiguous block** of memory.
* **Raw Data:** It stores raw bits (like C/C++ `int64` data) side-by-side.
* **Vectorization (SIMD):** Because data is contiguous, the CPU can load a huge chunk of numbers into a register and perform an operation (like addition) on all of them simultaneously (Single Instruction, Multiple Data) without explicit loops.

> [!DANGER] The Homogeneity Rule
> NumPy arrays **must** contain the same data type. If you try to mix types (e.g., `[1, 2, "A"]`), NumPy will **upcast** (force-convert) everything to the most complex type (Strings) to maintain structural integrity.

## 2. Array Anatomy (Inspection Attributes)

Before manipulating data, you must understand the geometry of your container.

| Attribute | Definition | Example Output | Mental Model |
| :--- | :--- | :--- | :--- |
| **`.ndim`** | Number of dimensions (axes). | `2` | Rank of the tensor (1=Line, 2=Grid, 3=Cube). |
| **`.shape`** | Tuple of dimensions. | `(3, 4)` | (Rows, Columns) / The geometry. |
| **`.size`** | Total count of elements. | `12` | Rows $\times$ Columns. |
| **`.dtype`** | Data type of contents. | `int64` | The "flavor" of the data. |
| **`.itemsize`**| Memory of **one** element (bytes).| `8` | 8 bytes for a 64-bit integer. |
| **`.nbytes`** | Total memory of array (bytes). | `96` | `.size` $\times$ `.itemsize`. |
```
