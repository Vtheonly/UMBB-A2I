# 2.4. Logic, Masking, and Searching

This is the most powerful feature in NumPy for data cleaning, completely replacing `if` statements inside loops.

## 1. Boolean Masking
Filtering data based on conditions.
1. **Create the Mask:** Compare array to a value (returns array of True/False).
2. **Apply the Mask:** Pass it inside `[]`.

```python
grades = np.array([5, 10, 15, 20])
passing = grades[grades > 10] # Output: [15, 20]
```

> [!DANGER] Logical Operators
> You **cannot** use Python's `and`/`or` keywords. They expect single True/False objects. For arrays, you must use Bitwise operators:
> * `&` (AND)
> * `|` (OR)
> * `~` (NOT)
> **Parentheses are mandatory:** `grades[(grades > 10) & (grades < 15)]`

## 2. `np.where` (The Swiss Army Knife)

`np.where` serves two distinct purposes depending on how you call it.

* **Usage 1 (Replacement):** `np.where(condition, val_true, val_false)`
  * *Example:* `np.where(grades > 10, 'Pass', 'Fail')`
* **Usage 2 (Search):** `np.where(condition)`
  * Returns a tuple of **indices** where the condition is True.

## 3. Finding Extrema (Max/Min)

* **`np.max(arr)`**: Returns the highest **value**.
* **`np.argmax(arr)`**: Returns the **flat index** of the highest value.
* **`np.unravel_index(flat_index, shape)`**: Converts the flat index from `argmax` back into proper `(row, col)` coordinates.

## 4. Sorting & Logic Checks

* **`np.sort(arr)`**: Returns sorted values.
* **`np.argsort(arr)`**: Returns the **indices** that would sort the array.
  * *Tip for finding Top N values:* `np.argsort(arr)[-5:][::-1]` (Gets indices of the top 5, reversed so highest is first).
* **`np.any(cond)`**: True if *at least one* element fits the condition.
* **`np.all(cond)`**: True if *every* element fits the condition.
