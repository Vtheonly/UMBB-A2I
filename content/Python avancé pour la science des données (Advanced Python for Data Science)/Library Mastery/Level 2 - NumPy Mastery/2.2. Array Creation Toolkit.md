# 2.2. Array Creation Toolkit

Never type out large arrays manually. NumPy provides highly optimized C-backed functions to generate data.

## 1. Standard Generators

* **`np.zeros((r, c))`**: Fills the shape with 0s. Default dtype is float.
* **`np.ones((r, c))`**: Fills the shape with 1s.
* **`np.full((r, c), value)`**: Fills the shape with a specific `value`.
* **`np.empty((r, c))`**: **Dangerous but Fast.** Allocates memory *without* clearing it. Contains "garbage" values from RAM. Fastest method if you plan to overwrite immediately.

## 2. Ranges (The Confusing Twins)

Students often confuse `arange` and `linspace`.

### `np.arange(start, stop, step)`
Works like Python's `range`. Focuses on the **step size**. 
* **Rule:** The `stop` value is **Exclusive**.
```python
np.arange(0, 5) # Output: [0, 1, 2, 3, 4]
```

### `np.linspace(start, stop, num)`
Focuses on the **total count of items**. Generates `num` evenly spaced points.
* **Rule:** The `stop` value is **Inclusive** by default.
```python
np.linspace(0, 10, 5) # Output: [0., 2.5, 5., 7.5, 10.]
```

## 3. Identity Matrices
* **`np.eye(N)`**: Creates an $N \times N$ matrix with 1s on diagonal and 0s elsewhere.
* **`np.identity(N)`**: Functionally similar to `eye`, but strictly forces a square matrix.

## 4. Advanced Builders (From Quizzes)
* **`np.fromiter(iterable, dtype)`**: Quickly builds an array from a Python generator/iterator without having to convert it to a list first.
* **`np.fromfunction(func, shape)`**: Executes a function `f(row, col)` over every coordinate index to determine the value at that position.

## 5. Randomness (`np.random`)

Crucial for initialization in Deep Learning and Simulations.

* **`np.random.seed(42)`**: Fixes the random state. Guarantees reproducibility. Run this first in experiments!
* **`np.random.rand(d0, d1)`**: **Uniform** distribution $[0, 1)$. All numbers equally likely.
* **`np.random.randn(d0, d1)`**: **Normal (Gaussian)** distribution ($\mu=0, \sigma=1$). (Bell Curve).
* **`np.random.randint(low, high, size)`**: Random integers. `high` is **Exclusive**.
* **`np.random.choice(array, size)`**: Picks random samples from a provided list/array.
