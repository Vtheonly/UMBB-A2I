# 2.3. Indexing, Slicing, and Reshaping

## 1. Slicing Syntax
* **Standard:** `arr[start:stop:step]` (Just like Python lists).
* **Reversing:** `arr[::-1]` reverses the array.
* **2D Slicing:** Uses comma notation `[row_slice, col_slice]`.
  * `arr[:, 1]` selects **all rows** of column index 1.
  * `arr[0:2, 0:2]` gets a 2x2 sub-matrix from the top-left corner.

> [!WARNING] View vs. Copy (High Priority Gotcha)
> Standard slicing returns a **VIEW**. `sub = arr[0:2]` does not copy memory. If you change `sub`, the original array changes too. To detach it, use `.copy()`: `sub = arr[0:2].copy()`.

## 2. Reshaping and Flattening

### Reshaping
* **`arr.reshape(r, c)`**: Changes geometry without changing data. `size` must remain identical.
* **The -1 Trick:** `arr.reshape(3, -1)` lets NumPy auto-calculate the 2nd dimension based on total size.

### Flattening (1D Conversion)
* **`arr.ravel()`**: Flattens to 1D. Returns a **View** (Fast, efficient memory usage).
* **`arr.flatten()`**: Flattens to 1D. Returns a **Copy** (Slower, but safe from mutation).

## 3. Stacking (Joining)
Gluing arrays together.
* **`np.vstack((a, b))`**: Vertical Stack (adds **Rows**). Same as `concatenate(axis=0)`.
* **`np.hstack((a, b))`**: Horizontal Stack (adds **Columns**). Same as `concatenate(axis=1)`.
* **`np.concatenate((a, b), axis=n)`**: General purpose joiner.

## 4. Type Conversion
* **`arr.astype(dtype)`**: Casts the array to a specific type (e.g., `arr.astype('float32')`). Crucial for memory management in large datasets.
