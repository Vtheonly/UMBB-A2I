# 3. Functions and Modular Code

## 1. Functions
Functions allow you to wrap code into reusable blocks.
*   **Definition:** `def function_name(parameters):`
*   **Return:** Sends a result back to the caller. If no return statement is used, it returns `None`.

```python
def greet(name):
    return f"Hello, {name}!"

# Functions can return multiple values (as a tuple)
def split_name(full_name):
    parts = full_name.split()
    return parts[0], parts[-1]

fname, lname = split_name("Ali Benali") # Unpacking the tuple
```

### Lambda Functions
Anonymous, one-line functions. Useful for short operations, especially inside `map`, `filter`, or `sort`.
*   **Syntax:** `lambda arguments: expression`

```python
square = lambda x: x**2
print(square(5)) # 25

# Practical use with sorting a dictionary list by a specific key
data = [{"name": "A", "age": 25}, {"name": "B", "age": 20}]
sorted_data = sorted(data, key=lambda x: x["age"]) 
```

## 2. File Handling
Python provides built-in methods to read/write files.

### The `with` Statement (Context Manager)
> [!WARNING] Critical Best Practice
> Always use the `with` statement when opening files. It automatically closes the file even if an error occurs inside the block, preventing data corruption and memory leaks.

```python
# Reading
with open("data.txt", "r") as f:
    content = f.read()

# Writing (Overwrites existing content)
with open("data.txt", "w") as f:
    f.write("Hello World")
```

### Handling CSV and JSON
*   **CSV:** Use the `csv` module. `csv.DictReader` is excellent as it treats rows as dictionaries (using headers as keys).
*   **JSON:** Use the `json` module. `json.load()` reads a file into a Python dict; `json.dump()` writes a dict to a file.

## 3. Scripts vs Modules vs Packages

### Structure
1.  **Script:** A standalone `.py` file intended to be executed directly.
2.  **Module:** A `.py` file containing functions/classes intended to be *imported* into other files.
3.  **Package:** A directory containing multiple modules and a special `__init__.py` file (which can be empty, but marks the directory as a package).

### The `if __name__ == "__main__":` Block
This is one of the most common questions in Python.
*   When you run a file directly, Python sets the special variable `__name__` to `"__main__"`.
*   When you *import* a file, `__name__` is set to the filename.

**Why use it?** It prevents code (like print statements or test logic) from running automatically when you simply want to import functions from that file.

```python
# utils.py
def helper():
    print("Helping...")

if __name__ == "__main__":
    # This block runs ONLY if you run 'python utils.py'
    # It will NOT run if you do 'import utils' in another file
    helper()
    print("Script executed directly")
```

## 4. Libraries and Pip
*   **Standard Library:** Modules built into Python (e.g., `math`, `os`, `random`, `datetime`). No installation needed.
*   **External Packages:** Installed via `pip` (Python Package Index).
    *   Command: `pip install pandas`
    *   Usage: `import pandas as pd`

**Naming Conventions (PEP 8):**
*   **Variables/Functions:** `snake_case` (e.g., `calculate_mean`).
*   **Classes:** `PascalCase` (e.g., `DataCleaner`).
*   **Constants:** `ALL_CAPS` (e.g., `PI = 3.14`).
