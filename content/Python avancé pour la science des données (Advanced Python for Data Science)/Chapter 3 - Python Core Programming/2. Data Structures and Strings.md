# 2. Data Structures and Strings

## 1. Lists
A generic, **mutable**, ordered sequence of elements. Lists can contain mixed data types.

**Common Operations:**
*   **Create:** `fruits = ["apple", "banana"]`
*   **Access:** `fruits[0]` (First item), `fruits[-1]` (Last item).
*   **Add:**
    *   `fruits.append("kiwi")`: Adds to the end.
    *   `fruits.insert(1, "orange")`: Inserts at index 1.
*   **Remove:**
    *   `fruits.remove("banana")`: Removes first occurrence of value.
    *   `fruits.pop(0)`: Removes and returns element at index 0.
*   **Slicing:** `list[start:stop:step]`
    *   `fruits[1:4]` (Items from index 1 to 3).
    *   `fruits[::-1]` (Reverses the list).

## 2. Tuples
Similar to lists, but **immutable**. Once created, you cannot change, add, or remove elements.
*   **Syntax:** `point = (10, 20)`
*   **Use Case:** Storing data that shouldn't change, like coordinates or database configuration. Faster than lists.

## 3. Dictionaries
Stores data in **Key-Value** pairs. Keys must be unique and immutable (strings, numbers, tuples). Values can be anything.

```python
person = {
    "name": "Ali",
    "age": 30,
    "city": "Alger"
}

# Accessing
print(person["name"]) 
print(person.get("email", "Not Found")) # Safer: returns "Not Found" if key missing

# Modifying
person["email"] = "ali@example.com" # Adds new key
person["age"] = 31                  # Updates existing key
```

## 4. Sets
Unordered collections of **unique** elements. Useful for removing duplicates and mathematical set operations.

```python
s1 = {1, 2, 3}
s2 = {3, 4, 5}

print(s1 & s2) # Intersection: {3}
print(s1 | s2) # Union: {1, 2, 3, 4, 5}
print(s1 - s2) # Difference: {1, 2}
```

## 5. Strings & F-Strings
Strings are immutable sequences of characters.

**String Interpolation (F-Strings):**
Introduced in Python 3.6, this is the modern, readable way to format strings.
```python
name = "Ali"
age = 30
# Embed variables directly inside {}
msg = f"My name is {name} and I am {age} years old."
# You can even do math inside
math_msg = f"Next year I will be {age + 1}." 
```

**Essential String Methods:**
*   `.lower()`, `.upper()`: Case conversion.
*   `.strip()`: Removes leading/trailing whitespace (crucial for cleaning user input).
*   `.split(delimiter)`: Breaks a string into a list (e.g., `"a,b,c".split(",")` → `['a', 'b', 'c']`).
*   `.join(list)`: Joins a list into a string.
*   `.replace(old, new)`: Replaces substrings.

## 6. Stacks and Queues (Data Structure Concepts)

### Stack (LIFO - Last In, First Out)
Think of a stack of plates. You add to the top and remove from the top.
*   **Python Implementation:** Use a `list`.
    *   `push` -> `list.append()`
    *   `pop` -> `list.pop()` (removes last element)

### Queue (FIFO - First In, First Out)
Think of a line at a store. The first person in line is the first served.
*   **Python Implementation:** Using a `list` is inefficient for queues (shifting elements is slow). Use `collections.deque`.

```python
from collections import deque
queue = deque(["A", "B"])
queue.append("C")    # Enqueue
queue.popleft()      # Dequeue (Removes "A") - Highly efficient
```

## 7. List Comprehensions
A concise way to create lists based on existing iterables. It replaces standard `for` loops for creating lists.

**Syntax:** `[expression for item in iterable if condition]`

```python
numbers = [1, 2, 3, 4, 5]

# Standard Loop
squares = []
for x in numbers:
    squares.append(x**2)

# List Comprehension (Equivalent)
squares = [x**2 for x in numbers]

# With Filtering (only even numbers)
evens = [x for x in numbers if x % 2 == 0]
```
