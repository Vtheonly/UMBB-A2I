# 5. Advanced Concepts: Iterators, Generators, and Exceptions

## 1. Iterators and Generators
These are essential for handling **large datasets** efficiently (e.g., 1 million patient records) where loading everything into a list (RAM) would crash the computer.

### Iterators
An object that represents a stream of data. It returns one element at a time using `__next__()`.

### Generators (`yield`)
A simpler way to create iterators using functions.
*   Instead of `return` (which sends a value and ends the function), generators use **`yield`**.
*   **`yield`** pauses the function, saves its state, and returns the value. When called again, it resumes exactly where it left off.

**Performance Comparison:**

**Bad Approach (List):**
Loads 1,000,000 lines into memory at once.
```python
def read_all_patients(filename):
    with open(filename) as f:
        reader = csv.reader(f)
        return list(reader) # CRASH: Memory Explosion
```

**Good Approach (Generator):**
Loads 1 line into memory, processes it, discards it, then loads the next.
```python
def read_patients_generator(filename):
    with open(filename) as f:
        reader = csv.reader(f)
        for row in reader:
            yield row # Efficient: One at a time

# Usage
for patient in read_patients_generator("huge_file.csv"):
    process(patient)
```

## 2. Error Handling (Exceptions)
Exceptions are runtime errors that disrupt the flow of the program. Handling them ensures your code is **robust**.

### Structure
*   **`try`**: Block of code that might cause an error.
*   **`except`**: Block that runs *if* a specific error occurs.
*   **`else`**: Runs if *no* error occurred in the try block.
*   **`finally`**: Runs **always**, regardless of errors. Used for cleanup (e.g., closing database connections).

### Best Practices
1.  **Be Specific:** Do not just catch generic `Exception`. Catch `FileNotFoundError`, `ValueError`, `ZeroDivisionError`, etc.
2.  **Use Finally:** Ensure resources are released.

```python
try:
    f = open("patients.csv")
    result = 10 / 0 # This will cause ZeroDivisionError
except FileNotFoundError:
    print("Error: File missing!")
except ZeroDivisionError:
    print("Error: Cannot divide by zero!")
else:
    print("Calculations successful.")
finally:
    # This runs whether the file opened or failed, or if division failed
    print("Cleaning up resources...")
    # (In real code, you would close 'f' here if it was open)
```
