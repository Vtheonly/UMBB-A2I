# 7. Main Python Libraries for Data Science

You don't need to reinvent the wheel. These libraries form the standard stack for data science.

## 7.1 Core Computing & Data Manipulation
*   **NumPy:** The fundamental package for scientific computing. It provides support for **arrays** (matrices) and high-level mathematical functions. It is much faster than standard Python lists.
*   **Pandas:** Built on top of NumPy. It provides **DataFrames**, which are like programmable Excel spreadsheets. It allows for easy data cleaning, manipulation, and analysis.

## 7.2 Visualization
*   **Matplotlib:** The grandfather of Python visualization. It creates static, animated, and interactive plots. It is very powerful but can have a steep learning curve for complex custom plots.
*   **Seaborn:** Built on top of Matplotlib. It provides a high-level interface for drawing attractive and informative statistical graphics. It makes complex plots (like heatmaps) easier to create.

## 7.3 Machine Learning
*   **Scikit-learn:** The go-to library for classical machine learning algorithms: Classification, Regression, Clustering, and Dimensionality Reduction. It also handles data preprocessing.
*   **XGBoost / LightGBM:** specialized libraries for **Gradient Boosting**. These are famous for winning Kaggle data science competitions due to their speed and performance on structured data.

## 7.4 Deep Learning
*   **TensorFlow:** Developed by Google. A comprehensive ecosystem for building deep neural networks.
*   **PyTorch:** Developed by Meta (Facebook). Known for its flexibility and "pythonic" feel. It is widely preferred in the research community.

## 7.5 Scientific & Statistical
*   **SciPy:** Used for advanced math, optimization, integration, and interpolation.
*   **Statsmodels:** Focuses on statistical modeling (like R-style formulas) and hypothesis testing.
